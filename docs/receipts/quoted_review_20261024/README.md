## Resulting behavior

`distillery.quoted-review/v7` retains a complete ordered candidate review for every requested fact. Each decision includes the exact requested property and exact supplied passage, followed by the model's relevance choice. The model also decides whether relevant sources agree. The constrained decoder emits supported wording as the selected passage, conflict wording with two distinct-source passages, or a refusal naming the missing property. It never substitutes or repairs generated text after completion.

The host enforces review completeness, exact property/quote identities, status/review consistency, retained requested-fact count and order, and matching claim-evidence links. Structured citation projection uses only those checked links; text inside a review, a prose string or a marker-like quotation cannot create a citation. Citation answer selectors address the particular claim's evidence quote, including Unicode scalar offsets, even when that quote appears earlier elsewhere in the output.

Eidetic keeps the review, requested fact set, raw-output identity and claim-to-passage support. Required replay semantics prevent downgrading a quoted-review artifact to an older contract. Historical prompt instructions v1 through v6 remain byte-identical. Turnstone displays a compact Model evidence review row and preserves the semantic-review warning.

## Evidence boundaries

This is a short-passage extractive envelope, with at most eight unique supplied handles. Individual supported text and each admissible pairwise conflict text must fit the existing 384 encoded-byte claim-text bound. Oversized candidate quotations, pairwise conflict wording, or grammars exceeding the original depth/node/literal-byte limits are refused before generation, never truncated or reclassified as insufficient evidence. This cohort uses short requested-property names; very long property names can still reach the final384-byte claim validation through the canonical refusal wording. Such a result fails the contract rather than being accepted as an answer.
